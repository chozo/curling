# カーリング

公開先: https://game.chozo.net/curling/ ／ ソース: https://github.com/chozo/curling

3D のカーリングミニゲームです。CPU と 1〜3 エンドで対戦します。1エンド目の先攻・後攻はプレイヤーが選べます。

## 操作

- **狙う**: 画面を左右にドラッグして、ハウスに置いた黄色い目印（スキップのブルーム）を動かす。ストーンは目印に向かってまっすぐ投げ出され、回転の分だけ途中から曲がる。白い破線とミニマップの点線が投げ出す向き。
- **回転**: 左下のボタンで「右に曲げる（時計回り）／左に曲げる（反時計回り）」を切り替える。切り替えると、目印は曲がる分（1.1m）だけ反対側の「おすすめの位置」に置き直される。
- **投げる**: 「投げる」を押すとパワーゲージが上下に動き（1往復 2.2 秒、一定の速さ）、画面のどこかをタップした時点の強さで投げる。ゲージの中にはハウスの輪をそのまま描いてあり、輪のところで止めればその位置に止まる（真ん中の白がティーライン）。ミニマップの黄色い線は、今のゲージで止まる位置（曲がりは含まない）。
- **スイープ**: 滑っているストーンの前に出る光る帯を左右にこする。速くこするほど効き、ストーンが伸びて曲がりが減る。

目印をおすすめの位置に置いてゲージの真ん中で止めれば、ボタンから約 10cm に止まる。ハウスに入るゲージの幅は全体の約 37%（約 0.4 秒）。ゲージの速さは `THROW.gaugePeriod`、ゲージと距離の対応は `THROW.powerCurve` で調整できる。

## 試合の進め方

- あなた（赤）と CPU（黄）が 4 投ずつ交互に投げ、エンドごとに得点を出す。エンド数は 1・2・3 から選ぶ。
- **先攻・後攻**: タイトルで1エンド目を選ぶ。先攻は先に投げ、後攻は最後の一投（ハンマー）を持つ。得点表の名前の横の「●」がハンマー。
- 2エンド目からは本来のルールどおり、得点したチームが次のエンドで先に投げる（ハンマーは相手へ）。ブランクエンド（0点）ならハンマーはそのまま。
- 最終エンドで同点ならエキストラエンドを行う。
- スイープできるのは自分の石だけ。CPU の石は CPU が掃く。

## CPU

- 同じ物理計算で候補の一投（ガード 2 種・ドロー 3 種・テイクアウト 2 種 × 狙い角 21 通り × 回転 2 通り、最大 294 通り）を試し、投げたあとの盤面を評価して選ぶ。上位 6 つは投げのぶれを入れて試し直し、際どすぎる一投を避ける。
- 評価: 最後の一投は得点そのもの（ハンマー側は 1 点より 0 点でハンマーを残す方を少し好む）。途中は得点の見込みに加えて、ハウス内の石の位置とガードの価値を足す。
- 考える処理は 1 フレームに 8ms ずつ分け、画面が止まらないようにしている（考える時間は全体で約 0.1 秒、演出として最短 0.9 秒は「考え中」を見せる）。
- 投げるときに、狙い角（標準偏差 0.0035rad）と距離（同 0.6m）のぶれが入る。ドロー・ガードは 0.5m 弱めに投げ、滑走中に「次の判断まで掃く／掃かない」を先読みして、狙いの地点に近く止まる方を選ぶ。
- 強さは `src/config.ts` の `AI`（ぶれの大きさ・候補の数）で調整できる。単体テストでは、ボタン狙いのドローだけを投げる相手（距離のぶれ ±2m）に 8 エンドで 7対4 と勝ち越す。

## 仕様（物理）

- シートの寸法は規格どおり（ホッグライン〜ティーライン 6.4m など）。滑走は実際の約 3.6 倍速（`GAME.simSpeed`）。
- 摩擦による減速は 0.08 m/s²。曲がりは「横向き加速度 = curl × 回転 / (速さ + 0.4)」で、遅くなるほど強く曲がる。ドローで約 1.1m 曲がる。
- スイープを最大にすると、摩擦が 30% 減り（ドローで約 2m 伸びる）、曲がりが 55% 減る。
- ストーン同士は反発係数 0.88 の円の衝突。バックラインを完全に越えた石、サイドボードに当たった石、奥のホッグラインを越えなかった石は除外。

調整値はすべて `src/config.ts` にあります。

## 開発

```sh
npm install
npm run dev      # 開発サーバー（スマホで試すときは npx vite --host）
npm test         # 単体テスト（物理: 曲がる量・スイープ・衝突・得点 / 投げる: ゲージと目印で狙った所に止まるか / CPU: 一投の選択・考える時間・スイープ判断・自動対戦）
npm run build    # 型チェック + dist/curling/ へ出力
npm run ogp      # OGP 画像（public/ogp.png）を作り直す
npm run promo    # 告知動画（../video/curling-promo.mp4）を作る
npm run deploy   # ビルドして Cloudflare Workers へ公開
npm run e2e      # ビルド後に実行（--url で公開先も確認できる）。ヘッドレス Chrome で、先攻・後攻の選択、目印のドラッグ、ゲージを止めて投げる、こする、CPU の手番、エンド進行とハンマーの受け渡し、勝敗、もう一度を確認
```

確認用の入口 `window.__game`（`state()`、`throwPower(ゲージ値, 目印x)`、`throwDist(距離, 狙い, 回転)`、`setTimeScale()`、`setSweep()`、自分の手番も CPU に投げさせる `setAuto(true)`、撮影用の `manual(on)` / `step(dt)` / `placeStones()` など）があります。

## ファイル構成

- `src/physics.ts`: 滑走・曲がり・スイープ・衝突・得点の計算（描画と無関係なので CPU の先読みにも使える）
- `src/scene.ts`: Three.js の描画（シート、ストーン、ブラシ、氷しぶき、カメラ）
- `src/ai.ts`: CPU の思考（候補の一投の先読みと評価、投げのぶれ、スイープ判断）
- `src/main.ts`: 試合の進行（エンド・ハンマー・得点表）、入力、画面表示
- `src/audio.ts`: Web Audio で合成した効果音（滑走音・スイープ音・衝突音）
- `src/config.ts`: 調整値
- `index.html`: 画面の骨組み。タイトル画面のストーン（顔つきの赤・黄）とブラシのイラストは、ここにインラインの SVG で描いている
- `public/favicon.svg`: アイコン（タイトル画面と同じタッチの、顔のある赤いストーン）
- `public/ogp.png`: SNS 共有用の画像（1200×630）。`npm run ogp` で作り直せる
- `tools/ogp/make-ogp.mjs`: OGP 画像の生成。確認用の入口（`manual` / `step` / `placeStones`）で盤面を作り、ハウスへ滑り込むストーンをスイープしている場面を撮って、ロゴ・タイトル画面のイラスト・遊び方・URL を重ねる。乱数を固定しているので毎回同じ絵になる（フォントは Google Fonts から読み込むため、作るときはネットワークが必要）

## 素材・フォント

- イラスト・アイコン・効果音はすべてコードで作成（外部の画像・音素材は使っていない）。
- タイトル画面のフォント: [M PLUS Rounded 1c](https://fonts.google.com/specimen/M+PLUS+Rounded+1c)（Google Fonts から読み込み、SIL Open Font License 1.1）。読み込めない場合は端末の丸ゴシック・標準フォントで表示する。

## 告知動画

`npm run promo` で、縦型（1080×1920、30fps、約 30 秒）の告知動画を作る。ゲームを 1 コマずつ進めて撮影するので、実時間の録画と違ってコマ落ちしない。

- 出力: `../video/curling-promo.mp4`（本編）、`curling-promo-cover.jpg`（表紙）、`curling-promo-sheet.jpg`（2 秒おきの一覧）。途中ファイルは `../video/work/`（消してよい）。動画はリポジトリに含めない。
- 台本: `tools/promo/scenario.js`。ダブルテイクアウトのつかみ → タイトル → ねらう・ゲージをタップ・こする → ボタン → CPU のテイクアウト（×4 早送り）→ ラスト一投で 4 点 → エンドカード。見せ場の盤面は `placeStones` で作り、狙い（強さ・目印）は物理計算で探した値を使っている。乱数の種は 6（`PROMO_SEED` で変えられる）。
- 構成だけ確かめる: `PROMO_EVERY=15 npm run promo`（15 コマおきの一覧 `../video/curling-promo-preview.jpg`。赤い領域はショート動画アプリの UI が重なる場所）。
- 音だけ直す: `PROMO_ENCODE_ONLY=1 node tools/promo/record.mjs`（撮り直さない）。
- 音: ゲームの効果音（滑走音・スイープ音・衝突音・投げる音）＋ `tools/promo/make-bgm.mjs` で一から合成した BGM（ヘ長調 F→C→Dm→B♭、BPM148、グロッケンで氷のキラキラ感）。外部の音源は使っていない。BGM は効果音より約 13 dB 小さく（`volume: 0.04`）、全体を -14 LUFS にそろえる。
- 道具（`record.mjs` / `stage.js` / `promo.css` / `make-bgm.mjs`）は promo-video スキルのひな形をコピーしたもの。見た目（`promo.css`）はタイトル画面に合わせて水色・紺・赤にしている。

## 公開

Cloudflare Workers（Static Assets）で `https://game.chozo.net/curling/` に公開しています。設定は `wrangler.jsonc`（Worker 名 `curling`、ルート `game.chozo.net/curling` と `game.chozo.net/curling/*`、workers.dev は使わない）。`npm run build` で `dist/curling/` に出力し、`npm run deploy` で公開します。

- 公開先の確認（2026-11-19）: `npm run e2e -- --url https://game.chozo.net/curling/` で、スマホ（360×640）と PC の操作・試合の進行がすべて合格。favicon・OGP 画像の取得と、同じドメインの他のゲームが表示されることも確認。
- スマホ実機での手触り・音は未確認。
